RHB Banking Group, Malaysia

RHB, one of Malaysia's largest banking groups, is a featured Dell customer for PowerProtect Cyber Recovery: business-critical data moves through an operational air gap into an isolated, immutable vault, where AI-driven analytics (CyberSense) validate every copy — so that after an attack the bank restores a copy it can prove is clean. The architecture is the one Dell's Sheltered Harbor-endorsed reference describes for financial institutions, and it is exactly the data path two of this repo's twins model as a pair.

RHB is a major Malaysian bank. To survive a ransomware attack — malware that encrypts a company's data and demands payment — it keeps a copy of its critical data in a "vault": a set of Dell systems that are disconnected from the network almost all the time (an "air gap"), where copies are locked so they cannot be altered. Software called CyberSense reads every copy byte by byte to certify which ones are clean. If an attack gets through, the bank restores from a copy it can prove was made before the attack — instead of guessing.
