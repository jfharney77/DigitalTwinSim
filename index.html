DigitalTwinSim

Interactive digital twins of Dell hardware and platforms — each a pure simulation engine behind a data-driven diagram, built to teach one idea per machine. Chips show which twins are running right now; start one with ./<Twin>/scripts/start_all.sh. Real customer deployments assembled from these twins live in the CustomerSetup gallery.
